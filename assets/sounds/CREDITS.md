# Bundled sounds

All sounds here are **CC0 1.0** (public domain dedication), which permits
redistribution inside this crate. No attribution is required; it is recorded
here anyway.

| file | source | author |
|------|--------|--------|
| `cork.wav` | [Champagne cork #1](https://bigsoundbank.com/champagne-cork-s0211.html) — [BigSoundBank](https://bigsoundbank.com/) | Joseph SARDIN |

Files are trimmed, level-matched and converted to 22.05 kHz mono 16-bit WAV —
the one format `afplay`, `pw-play`, `paplay` and `aplay` all read.
